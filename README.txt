# Gender Roles in the Philippines — MCO 1

This student-made HTML + CSS + JavaScript website was redesigned around the provided MCO 1 assessment rubric.

## Files
- index.html — structure, content, navigation, multimedia, references
- style.css — responsive visual design
- script.js — timeline, comparison, modals, mobile menu, animations
- assets/timeline.svg — original student-project illustration
- assets/roles-infographic.svg — original student-project infographic

## Run locally
Open index.html directly or use VS Code + Live Server.

## GitHub Pages
The repository root must contain index.html, style.css, script.js, and the assets folder. GitHub Pages should be configured to deploy from the main branch and / (root).
